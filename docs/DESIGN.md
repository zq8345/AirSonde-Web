## 0. 总命题

**全站唯一转化目标 = 一封合格的询盘。**
任何新板块 / 新页面 / 新功能立项前，先回答："它让访客离发询盘更近了吗？"答不上来就不做。

## 1. 目标用户与话术优先级

- **P1 品牌方**（美/欧品牌产品经理，最值钱）→ 要听"**可定制的平台**"
- **P2 进口/分销商** → 要听"**拿来就能卖的成品线**"
- **P3 机构买家**（学校/办公/工业，顺带）→ Solutions 承接
- **P0 AI 引擎**（获客主渠道）→ 只引用第一手内容
- ⚖️ **P1 与 P2 话术冲突时，P1 优先。**

## 2. 文案红线（诚实宪法）

1. **无证据不断言**：认证零名字（直到工厂交出真文件）、传感器技术不虚标、数字须可溯源。
2. **商业条款不上官网**（MOQ / 价格 / 周期 / 认证细节），一律导向询盘。
3. **产品图 / 文案 / 产品数据 = Joe 的内容资产**：窗口发现问题只报告，绝不代改。

## 3. 视觉语言

- **字体**：Inter 唯一家族；字号/字重以 AU3 层级表（docs/audit/2026-08-28-typography-audit.md）为准，**不新造档位**。
- **色**：暖米白底 + 深墨 + 品牌绿，以 light.css 现行 tokens 为准，**不加第二装饰色**。
- **影像两轨制**：AI 渲染场景图（2880×1200 · 2.4:1 · 主体避上下边 · 文字侧留白）管气质；真实工厂/产线照管信任；**两轨不互相冒充** —— 渲染图不得配事实性说明文字。
- **hero 规范**：文字落留白区、蒙版最小加深、最差 srcset 变体对比度 ≥4.5、高度 cap 2.8；**hero h1 必须是第一屏最重的文字**。

## 4. 版式与验收

- 容器 / 间距 / 圆角以现行 tokens 为准，新板块不得新造数值。
- **一切视觉改动的验收判据落在渲染值（computed / 实测），不落源码。**
